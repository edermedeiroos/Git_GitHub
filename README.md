# Estudos de Git e GitHub 🚀

Repositório criado para praticar conceitos de versionamento com Git e GitHub, desenvolvido durante as aulas do curso de Git e GitHub (Curso em Vídeo).

---

## 📂 Estrutura do Repositório

O repositório contém projetos práticos e exercícios:

- **`projeto-site/`**: Website com páginas de cursos (HTML5/CSS3 e JavaScript), contendo folha de estilos (`estilos/style.css`) e imagens.
- **`site-exemplo/`**: Página inicial simples de exemplo ("Meu primeiro site em repositório"), utilizada para os primeiros commits e testes de branches.

---

## 🛠️ Tecnologias e Ferramentas

- **Git** (controle de versão, commits, branches e merges)
- **GitHub** (hospedagem remota do código)
- **HTML5** e **CSS3**
- **JavaScript**
